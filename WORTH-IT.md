# WORTH-IT Protocol

> **TRIGGER:** You are about to spend more than 30 minutes on something, or create a new abstraction/table/system.

## QUESTIONS:

1. What specific problem does this solve?
2. Who benefits and how soon?
3. What is the simplest thing that could work? (not the most elegant)
4. Is there an existing tool/table/view that already does 80% of this?
5. If I do not do this, what actually breaks?

**IF THE ANSWERS ARE VAGUE:** You are gold-plating. Do the simpler thing.

## THE 80/20 RULE

- Can you get 80% of the value in 20% of the time? Do that first.
- The remaining 20% of value usually is not worth 80% more time.
- "Good enough and shipped" beats "perfect and still in progress."

## RED FLAGS

- "This would be cleaner if I also..." -- stop, ship what you have
- "While Im here I might as well..." -- stop, file a separate task
- "This needs a proper abstraction" -- does it? Or does it need to work?
- Building a dashboard when a Supabase query would suffice
- Creating a new table when an existing one could gain a column
